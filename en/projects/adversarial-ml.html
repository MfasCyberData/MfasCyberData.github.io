01 / Overview

A model can score highly on clean images and still react poorly to small, intentional perturbations.

The project measures that gap on MNIST using FGSM, then tests whether adversarial training improves the balance between clean accuracy and accuracy under attack.

Question

What happens under attack?

Evaluate ε = 2/255, 4/255 and 8/255.

Defense

Does adversarial training help?

Train a second model with a mix of clean and FGSM examples.

02 / Setup

A controlled experiment with fixed parameters and saved artifacts.

Data

MNIST

60,000 training images and 10,000 test images.

Model

CNN · 3,274,634 parameters

Two convolution layers, two fully connected layers and dropout.

03 / Method

The same evaluation protocol was applied to the baseline and defended models.

01

Baseline

Train five epochs on clean images and measure test accuracy.

02

FGSM

Create input-gradient perturbations bounded at 2/255, 4/255 and 8/255.

03

Defense

Train eight epochs with 50% clean and 50% adversarial examples, training ε 8/255.

05 / Reproducibility

Parameters, models, results and plots were saved.

The public repository contains the notebook, dependencies, trained models, JSON results and charts. Controls include L∞ bounds, input-gradient availability and visual inspection of perturbations.

Open GitHub repository ↗

06 / Limits

FGSM is a useful first baseline, not a complete robustness evaluation.

Attack strengthSingle-step baseline

Stronger iterative attacks such as PGD and broader suites such as AutoAttack are needed before making general robustness claims.

BenchmarkMNIST is educational

Results do not automatically transfer to complex images or production models.

07 / Takeaways

The main value is the measured, reproducible experimental workflow.
